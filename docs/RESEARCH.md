## 定点とは

特定の立ち位置と照準位置を覚え、決まった場所へ正確にスキルを飛ばすテクニック。主な用途:

| 用語 | 意味 |
|---|---|
| 定点 / ラインナップ | 立ち位置と照準を固定してスキルを当てる技術そのもの |
| 攻め / 守り | サイドごとの定点。攻めは初動の索敵・エントリー用、守りは遅延用 |
| 設置後（ポストプラント） / 解除阻止 | スパイク設置後、遠くから解除を止める定点。モリー系が中心 |
| リテイク | 取られたサイトを取り返すための定点 |
| ワンウェイ | 片側からだけ見えるスモーク（オーメン、ヴァイパーのオーブなど） |
| セットアップ | センチネルのトラップ・カメラ配置（置きカメラ など） |
| 空爆 / モリー | 投擲系の範囲ダメージスキルの定点（ヴァイパー C、ブリムストーン Q など） |
| ジャンプ投げ / 反射（バウンス） | 投げ方の種類 |

### 既知の注意点

- タグはタイトルから自動で推定しているため、タグなしの動画も多い
- 定点のまとめ動画に加えて、一部は定点を含むマップ攻略ガイド（主にアストラ・ブリーチ）
- 古い動画（2022〜2023 年）は、他に見つからなかった組み合わせの穴埋めにだけ使っている。マップ改修で使えなくなった定点が含まれる可能性がある

## 特集（モロトフ・ショート）の収集（2026-09-25）

- **モロトフ定点**: ブリムストーンのインセンディアリー、ヴァイパーのスネークバイト、キルジョイのナノスワーム、KAY/O のフラグ/メント、ゲッコーのモッシュピット、フェニックスのホットハンズを対象に 195 本を追加（`data/sources/molotov.json`、全件に `"tags": ["molly"]`）。既存の動画もタイトルにモロトフ系の語があれば自動でタグが付き、合計 314 本
  - 日本語では遠投の範囲ダメージ定点を「空爆」と呼ぶことが多いため、「空爆」もモロトフのタグに含めている。VCT の「空爆アビリティまとめ」のように、純粋なモロトフ以外も含む動画が一部ある
  - サミットのヴァイパー・キルジョイ、アビスのヴァイパー、スプリットのゲッコーは見つからなかった
- **ショート定点**: YouTube のショート検索（ショートのフィルター付き）で約 180 クエリを実行し、条件に合う約 557 本から、エージェント × マップごとに最大 2 本（複数マップは 1 本）の 178 本を追加（`data/sources/shorts.json`）。既存・モロトフ分を含めショートは合計 214 本
- **ショートの判定**: oEmbed に `https://www.youtube.com/shorts/<ID>` を渡したとき、ショートだけ縦長（113x200）が返る。`watch?v=<ID>` を渡すとショートでも横長（200x113）が返るので判定に使えない。`npm run shorts` がこの方法で sources に `"short": true` を付ける
- 埋め込みが無効な動画（oEmbed が 403）はサイト内で再生できないため除外した

### X での定点の形式

- 短いクリップが主流（148 件中 136 件がメディア付き）。画像だけの投稿は少ない
- 1 投稿 1 定点（または同じ位置から撃てる 2〜3 本）が基本。「定点集」は YouTube 動画の告知になっていることが多い
- 本文は「マップ＋エージェント＋サイト＋用途（開幕・設置阻止・解除阻止・リテイク・ワンウェイ）」の 1 行が定番
- ハッシュタグは #VALORANT がほぼ必ず付き、#ヴァロラント、エージェント名（#ソーヴァ）、マップ名（#カロード定点、#サミット）が続く。#VALORANT定点 は検索でほとんど見つからず、定着していない。英語圏は #VALORANT かブランドタグ（#ProLineups）

### YouTube との違い

- **速さ**: 新マップ（カロード・サミット）やマップ改修の数日以内に X に定点が出る。X で単発を出し、反応を見て後日 YouTube に「定点集」を出す流れがある
- **粒度**: X は 1 本単位で要点だけ（10〜30 秒、解説は少なめ）。YouTube は網羅的で、タイムスタンプや解説が付く。X は「覚えるきっかけ」、YouTube は「練習用の資料」
- **リンク切れ**: 削除や鍵アカウント化で見られなくなりやすい（今回 8 件が 403/404）。`npm run verify` で X のポストも定期的に確認する
- **偏り**: ソーヴァ・フェイド・ヴァイパーに大きく偏る
- **導線**: 多くの投稿は YouTube や外部サイト（ValoPoint、strats.gg、tricks.gg）への誘導を兼ねている

## 画像・データ

- エージェント・マップの名前と画像は [valorant-api.com](https://valorant-api.com)（コミュニティ運営・キー不要）から取得。`language=ja-JP` で日本語クライアントの名称が得られる
- 通常マップは `tacticalDescription` があるものに絞っている（チームデスマッチのマップや射撃場を除外）
- ブランドカラーは playvalorant.com のソースと同じ値: `#FF4655`（レッド）、`#0F1923`（ネイビー）、`#ECE8E1`（オフホワイト）
- フォントは公式の Tungsten / DIN Next が商用フォントのため、公式サイト自身も代替に使っている Anton、DIN 系の Barlow、Noto Sans JP で代用
